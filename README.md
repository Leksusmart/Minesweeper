# Minesweeper

Minesweeper - это игра, в которой необходимо обезвредить все мины на поле. Игроку показано количество мин, а также при открытии клетки на ней показывается число бомб, расположенных рядом с этой клеткой.

## Функции

- **Интуитивно понятный интерфейс**: Легкий в использовании интерфейс, ничего сверх сложного.
- **Сохранение и загрузка**: Ваши настройки и рекорды сохраняются в файле json. Так что при заходе в игру данные загрузятся из файла.

## Установка

- Соберите проект с помощью инструкции ниже
- Или загрузите исполняемый файл `Minesweeper.exe` из последнего релиза.

## Сборка проекта

Если вы хотите собрать проект самостоятельно, выполните следующие шаги:

1. Убедитесь, что у вас установлен MinGW и добавлен в переменную окружения `PATH`.
2. Склонируйте репозиторий или загрузите его на свой компьютер.
3. Откройте командную строку и перейдите в каталог проекта.
4. Создайте папку для сборки:
   ```bash
   mkdir build
   cd build
   ```
5. Запустите CMake для генерации файлов сборки:
   ```bash
   cmake .. -G "MinGW Makefiles"
   ```
6. Выполните сборку проекта:
   ```bash
   mingw32-make
   ```

## Использование

- Запустите приложение, и вы увидите стартовое окно с кнопкой играть и выбором сложности.
- Выберите сложность.
- Нажмите кнопку играть.
- Кликая на клетки в центре, вы открываете их, открыв все клетки, не содержащие бомбы, вы побеждаете.

## Системные требования
